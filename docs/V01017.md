# v0.10.17 — Fondations auto : chaîne géotechnique + exécution

## Relation des référentiels
- **NF P94-261 / Eurocode 7** : justification géotechnique des fondations superficielles.
- **NF DTU 13.1 P1-1** : domaine et mise en œuvre des fondations superficielles/semi-profondes.
- **Localisation / RGA** : contraintes particulières de profondeur lorsqu'elles sont applicables.

Le logiciel ne présente pas le DTU 13.1 comme une méthode de calcul de portance.

## Localisation
- code postal → recherche de commune via geo.api.gouv.fr ;
- adresse optionnelle → géocodage plus précis ;
- interrogation Géorisques RGA ;
- un résultat au centre de commune est signalé comme indicatif.

## Pré-dimensionnement géotechnique
Le logiciel n'invente jamais la portance du sol à partir du code postal. L'utilisateur renseigne qRd (kPa) et NEd (kN/m).
Pour une semelle filante centrée en préétude : B = NEd / qRd.
Pour longrines + semelles isolées, un appui carré commun indicatif est estimé par longueurs tributaires.

## Profondeur RGA
Si la voie des dispositions types est explicitement sélectionnée : moyenne 0,80 m ; forte 1,20 m, sous réserve des conditions et exceptions du texte.

## Limites
Excentricité, efforts horizontaux, inclinaison, pente, eau, tassements, interaction de fondations, ferraillage, sismicité et conditions complètes de chantier restent à justifier.
