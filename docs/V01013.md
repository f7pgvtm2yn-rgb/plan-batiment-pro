# v0.10.13 — validation du solivage avant calcul

Correction du cas où l'étape 3 affichait plusieurs erreurs rouges et 0 solive.

- Les trois confirmations de l'étape 1 sont désormais obligatoires avant le lancement du calcul : maintien latéral prévu, charges du scénario vérifiées, et absence de mur/poteau repris directement sur les solives.
- Ces confirmations restent explicites : le logiciel ne les coche jamais automatiquement.
- La première passe de dimensionnement utilise une altitude supérieure provisoire. L'erreur « arase des appuis / sous-face non coordonnées » issue uniquement de cette passe provisoire ne bloque plus la recherche de section.
- La coordination réelle des hauteurs reste contrôlée dans la passe finale.
- Les autres erreurs structurelles réelles restent bloquantes.

Cette mise à jour ne modifie pas l'appui dynamique, les rives, ni le choix de sens de la v0.10.12.
