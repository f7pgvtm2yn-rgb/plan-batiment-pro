# v0.10.5 — solivage multi-travées cohérent

Le calcul du solivage traite désormais les travées rectangulaires ensemble. Le choix « Auto · portées courtes » reste une préférence : si deux travées voisines utiliseraient le même mur de façon incohérente, le moteur retourne seulement la ou les travées nécessaires pour rendre l'appui commun cohérent.

Le résultat conserve les garde-fous structurels existants. Si aucune combinaison cohérente n'est trouvée, la génération reste bloquée et indique le nombre de raccords à étudier. Quand une travée porte sur un mur partagé et que la voisine lui est parallèle, le solivage est conservé ; aucune rive de fermeture n'est inventée sur ce mur commun.

L'assistant affiche le nombre de travées dont le sens a été ajusté automatiquement. Les appuis de 15 cm, les rives automatiques, les hauteurs, les matériaux et les contrôles de préétude restent inchangés.

Cette logique est une aide géométrique et une préétude. Elle ne remplace pas la vérification des appuis, assemblages, chevêtres, charges, vibrations et transferts par une étude structure.
