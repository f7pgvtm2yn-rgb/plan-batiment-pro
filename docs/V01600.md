# v0.16.0 — Ruban de commandes et suppression de niveau

## Interface type Word / Excel / Sheets
L'espace de travail utilise désormais un ruban supérieur avec les onglets :
- Projet
- Architecture
- Structure
- Toiture
- Isolation
- Pièces & annotations
- Affichage
- Extensions

Les commandes existantes sont déplacées sans remplacer leurs gestionnaires d'événements.

### Commandes futures
Les futurs modules peuvent rejoindre le ruban avec :
- `PBPRibbon.register(...)`
- ou les attributs `data-ribbon-tab` et `data-ribbon-group`.

Les nouveaux boutons ajoutés à l'ancien panneau d'outils sont récupérés dans l'onglet Extensions comme filet de sécurité.

## Suppression d'un niveau
Le cartouche principal contient maintenant **− Niveau** à côté de **+ Niveau**.

Une fenêtre de confirmation indique les objets liés qui seront supprimés. La validation exige une case de confirmation.

La suppression nettoie :
- éléments du niveau ;
- planchers liés ;
- anciens calculs structure liés ;
- doublages/cloisons de second œuvre liés ;
- toitures prenant appui sur ce niveau ;
- fonds de plans importés ;
- noms de pièces de ce niveau ;
- automatismes de fondations qui référencent le niveau (désactivés).

Les niveaux Fondations, RDC, Toiture et les niveaux de plancher générés automatiquement sont protégés contre une suppression directe.

La suppression passe par l'historique du projet et peut être annulée avec la commande Annuler.
