# v0.11.0 — Noyau autonome et contexte sismique

## Projet autonome
- modes Automatique / Expert ;
- maison plain-pied, maison à étage, immeuble d’habitation ou autre ;
- état central des moteurs Fondations, Planchers/Solivage, Structure, Charpente, Menuiseries, Permis et 3D ;
- données manquantes explicites ; aucune donnée d’ingénierie n’est inventée.

## Sismicité de construction
- récupération automatique de la zone 1 à 5 via Géorisques et le code INSEE ;
- maison individuelle : catégorie d’importance II en automatique ;
- habitation collective : II jusqu’à 28 m, III au-delà ;
- valeurs agr : zones 1→5 = 0,4 / 0,7 / 1,1 / 1,6 / 3,0 m/s² ;
- coefficients gammaI : I=0,8 ; II=1,0 ; III=1,2 ; IV=1,4 ;
- calcul affiché ag = gammaI × agr ;
- classe de sol A à E et coefficient S ;
- détection générale de l’applicabilité des règles parasismiques aux bâtiments neufs : catégories III-IV en zone 2 ; catégories II-IV en zones 3 à 5.

Le module ne présente pas encore un calcul Eurocode 8 complet : spectre, masses, régularité, système de contreventement, ductilité, combinaisons et vérification des éléments restent à intégrer dans les moteurs structurels.
