# v0.17.0 — Nouvelle interface Plan Bâtiment Pro

## Structure générale
- barre d'application en haut : Nouveau, Enregistrer, Ouvrir/Exporter, Import de plan, Annuler/Refaire, vues ;
- onglets métier : Accueil, Construction, Structure, Toiture, Second œuvre, Réseaux, Terrain, Documents ;
- ruban contextuel sous les onglets ;
- navigateur du bâtiment à gauche ;
- plan 2D/3D au centre ;
- panneau Propriétés ancré à droite ;
- bandeau compact d'affichage/aimantation sous le ruban.

## Navigateur des niveaux
Chaque niveau possède un menu `•••` :
- Renommer ;
- Dupliquer ;
- Modifier l'altitude ;
- Ajouter un niveau au-dessus ;
- Supprimer le niveau.

Le bouton **− Niveau** reste aussi disponible en bas du navigateur.

## Suppression de niveau
La suppression conserve la sécurité de la v0.16 :
- fenêtre de confirmation détaillée ;
- case de confirmation obligatoire ;
- suppression des éléments du niveau et nettoyage des planchers, calculs structure, second œuvre, toitures, fonds importés et noms de pièces liés ;
- Fondations, RDC, Toiture et niveaux structurels générés protégés contre la suppression directe ;
- opération annulable via l'historique du projet.

## Commandes futures
Les futurs modules peuvent enregistrer une commande avec `PBPRibbon.register(element,{tab,group})` ou les attributs `data-pbp-tab` / `data-pbp-group`.
