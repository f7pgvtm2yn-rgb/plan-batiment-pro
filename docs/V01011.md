# v0.10.11 — appui dynamique des solives

Plan Bâtiment Pro utilise désormais la règle de projet suivante, sans prise en compte de connecteurs ou sabots :

**appui = max(5 cm ; épaisseur du mur / 2 − 0,5 cm)**

Exemples :
- mur 32 cm → appui 15,5 cm ;
- mur 20 cm → appui 9,5 cm ;
- mur 12 cm → appui 5,5 cm ;
- mur 10 cm → calcul théorique 4,5 cm, donc appui retenu 5 cm.

Les murs d'épaisseurs variables sont traités portion par portion. Une rive extérieure utilise la largeur restante après l'appui calculé. Deux solivages face à face utilisent chacun leur appui dynamique ; la rive centrale utilise la largeur résiduelle. Si deux appuis minimaux ne tiennent pas dans le mur, le calcul est bloqué.

Les rives longitudinales le long des murs parallèles sont conservées. Aucun mode « connecteur/sabot justifié » n'est disponible dans cette version.
