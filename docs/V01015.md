# v0.10.15 — scénario standard de préétude

Les trois cases obligatoires de l'étape 1 du Solivage automatique sont supprimées.

Le calcul utilise désormais un scénario standard clairement affiché :
- bois C24 ;
- maintien latéral supposé pour la comparaison de sections ;
- charges saisies dans l'assistant ;
- aucune reprise de mur ou poteau directement sur les solives.

Ces hypothèses ne sont pas présentées comme des faits validés : elles servent uniquement à lancer la préétude. Les éléments réellement détectés sur le plan (mur/poteau dans une travée, trémie, section insuffisante, etc.) restent bloquants.

L'utilisateur n'a donc plus trois cases répétitives à cocher à chaque calcul.
