# v0.10.14 — correction visuelle 3D

Cette version corrige le rendu sans modifier les calculs ni la géométrie enregistrée.

- Les abouts de solives sont tronqués uniquement pour l'affichage 3D à la face intérieure du mur porteur. L'appui calculé reste inchangé dans le modèle.
- Cela évite les petits rectangles bois visibles à travers une façade ou un mur.
- Les polygones 3D sont nettoyés : points doublons, micro-segments et points colinéaires sont supprimés avant triangulation.
- Les nœuds où trois murs ou plus se rejoignent reçoivent un petit raccord géométrique de rendu pour supprimer les trous, triangles et défauts d'angle.
- Les rives de fermeture utilisent une teinte cohérente avec leur matériau au lieu d'un artefact brun générique.
- Le cache-buster des modules passe réellement à v0.10.14 ; l'ancien index chargeait encore les scripts avec ?v=0.10.8, ce qui pouvait laisser une ancienne version en cache.

Aucune cote, appui, section, altitude ou quantité n'est modifiée par ce nettoyage visuel.
