# Publication de Plan Bâtiment Pro v0.10

Cette publication reprend les quatre modules du fichier de test v0.10 : assistant de solivage en trois étapes, aimant des murs, repères de structure entre niveaux et rendu 3D avec tampon de profondeur. Le bouton Solivage auto est placé sous Fondations auto. Les commandes de création manuelle de solivage sont masquées, sans effacer les anciennes données.

Le moteur historique et les modules de calcul v0.9 sont conservés. Le chargeur installe les deux points d'accroche de l'aimantation dans les gestes existants, après vérification des marqueurs du moteur. Les modules sont chargés dans un ordre explicite, avec contrôle d'initialisation.

La clé de sauvegarde de production reste `planBatimentPro`. La clé distincte du fichier de test local n'est pas utilisée sur le site. Les sauvegardes restent dans le navigateur, et non sur GitHub. Enregistrer avant de recharger le logiciel.

Vérifications lors de la publication : 16 tests structure et 23 tests bâtiment existants réussis ; syntaxe des quatre modules vérifiée ; empreintes des contenus transférés contrôlées. Tests d'interaction hors ligne dans Chromium, avec stockage simulé : initialisation, emplacement du bouton, parcours de l'assistant, refus de génération sans hypothèses, génération sur un rectangle d'essai, rendu 3D par tampon de profondeur logiciel, références au niveau inférieur et restauration du projet. Aucune erreur JavaScript observée dans ce scénario. Le chargeur de production a aussi été vérifié : les accroches du moteur sont identiques à celles du fichier testé, en conservant la clé de sauvegarde de production.

Ces vérifications sont des tests logiciels. Les calculs restent des préétudes partielles, et ne constituent pas une validation pour construire. Les limites de STRUCTURE.md, FONDATIONS.md et BATIMENT.md restent applicables. Le rendu 3D ne corrige pas les vrais écarts d'altitude du projet et ne certifie pas les raccords constructifs.
