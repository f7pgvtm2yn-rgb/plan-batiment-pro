# v0.17.1 — Interface compacte

La structure v0.17 est conservée mais ses proportions sont réduites.

- barre principale : 36 px environ ;
- onglets métier : 27 px ;
- ruban : 54 px ;
- bandeau affichage : 25 px ;
- navigateur niveaux : 172 px ;
- propriétés : 225 px ;
- boutons et groupes du ruban réduits.

## Panneaux repliables
- chevron dans le navigateur de niveaux ;
- chevron dans le panneau Propriétés ;
- repli = 32 px seulement ;
- recalcul immédiat de la taille des vues 2D/3D.

Sur petits écrans, les panneaux démarrent repliés et peuvent être ouverts temporairement.

La suppression de niveau et son menu de confirmation sont conservés sans changement fonctionnel.
